Collect NYC pool pages

This page can't fetch nycgovparks.org itself — browsers block a local file from reading another site. So the download runs on nycgovparks.org, in your own browser session, after you've passed its check.

  2. Open nycgovparks.org/facilities/indoor-pools and complete the captcha if shown, until the real pool list loads.
  3. Open DevTools (⌥⌘J), paste the script into the Console, press Return. (Chrome may ask you to type allow pasting first.)
  4. Wait about 30 seconds. It saves nycgov_cache.json to Downloads.
  5. In the repo: 
    NYC_POOLS_CACHE=~/Downloads/nycgov_cache.json ./scripts/refresh.sh

About 52 page loads, one every ~0.5s — what opening each pool page by hand would do. If any page returns the challenge instead of content, the script stops and says so rather than saving junk.
